# ImportNow clone– Website Recreation

An interactive, responsive website recreation inspired by the ImportNow reference website, built using HTML, CSS, JavaScript, and Three.js.

The project focuses on creating an engaging logistics and international trade experience through modern web design, interactive 3D visualizations, and responsive user interfaces.

## 📌 Project Overview

ImportNow is a website recreation project designed around international shipping, logistics, and global trade.

The website combines a modern user interface with interactive 3D scenes to represent global trade routes, shipping operations, and logistics infrastructure.

The implementation includes independently developed frontend code and procedurally created 3D visual elements.

## ✨ Key Features

- **Interactive 3D Earth:** A Three.js-powered globe representing global connectivity and trade.
- **Global Trade Visualization:** Animated trade routes and shipping journey elements.
- **3D Shipping Environment:** Container ships, ports, cranes, sky, and reflective water.
- **Responsive Design:** Layouts designed to adapt to different screen sizes.
- **Blog Section:** Blog listing and individual post pages.
- **Blog Search and Filters:** Helps users find relevant articles.
- **FAQ Section:** Frequently asked questions with interactive elements.
- **WhatsApp Quote Form:** Contact interaction for quotation enquiries.
- **Modern UI:** Clean layouts, visual elements, and interactive navigation.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/aishwaryaneela/importnow-clone-website.git
```

### 2. Navigate to the project folder

```bash
cd importnow-clone-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 5. Create a production build

```bash
npm run build
```

The production-ready files will be generated inside the `dist` directory.
